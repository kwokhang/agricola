# Agricola — 1–2 人局（修訂版 2016）

喺瀏覽器直接開 `game/index.html` 就玩得，冇 build step、冇 server。
規則出處同細節見 [`../docs/RULES-NOTES.md`](../docs/RULES-NOTES.md)。

| 檔案 | 做乜 |
|---|---|
| `index.html` | 版面同 CSS，載入 `../data.js`、`art.js`、`engine.js`、`ui.js` |
| `engine.js` | 純規則狀態機，冇 DOM |
| `art.js` | 全部圖畫：物資圖示、農場板（房屋／田／牧場／柵欄／動物）、行動格插圖 |
| `ui.js` | 畫面同點擊處理，狀態存喺 `localStorage` |

介面由三幅畫出嚟嘅板組成，唔係一堆 HTML 方格：

- **行動板**：每格一幅風景插圖（森林、採石場、河、牧場……），下面有羊皮紙名牌，
  累積物資畫成木製代幣連數字，有人放咗就壓暗並企個 meeple 上去。
- **農場板**：房屋按木／黏土／石頭畫唔同牆身，田有犁溝同作物，牧場圍柵有木樁同橫欄，
  動物同容量標記全部畫喺板上。點擊區就係板本身。
- **玩家板**：物資放喺凹槽入面，每格一個手繪圖示同數字，上面一條牌寫住房屋、柵欄、馬廄同人手。

卡片用真卡樣式：頂部色帶分職業／次要／主要發展，勝利分係一個蠟印。
深色淺色主題各有一套顏色，全部圖形都係 inline SVG，冇外部圖檔。

## 自動處理
- 10 個固定行動格 + 14 張回合卡（每階段內洗勻，順序唔會提前公開）。
- 補充／工作／回家／收成四個階段，輪流放人，人用完自動跳過。
- 農場板：犁田同房間嘅相鄰限制、馬廄上限 4 個、柵欄上限 15 條。
- 牧場：柵欄圍成密封區先算牧場，容量每格 2 隻、每個馬廄翻倍，一個牧場只放一種動物；牧場外馬廄 1 隻、屋企 1 隻寵物。
- 起唔到牧場嘅柵欄唔准完成，可以一鍵取消今次放低嘅柵欄。
- 播種、收割、餵食（單人 3 食物／成人、新生兒 1）、乞討標記、繁殖。
- 烤麵包同「任何時候」煮食，跟你手上嘅火爐／烹飪爐灶／黏土烤爐／石烤爐比率計。
- 計分表全部項目，包括田上未收嘅穀物蔬菜。

## 要自己做
96 張職業同次要發展卡嘅效果**唔會**自動結算 —— 卡文照原文顯示，用「手動調整」面板加減物資、動物同乞討標記。同樣要自己加嘅有：
- 卡上嘅獎勵分（吹噓者、細木工坊、陶器坊等）。
- 放喺回合格上嘅物資（水井、大溫室、泥屋建造者等）。
- 用火爐換烹飪爐灶。
- 單人局旅行卡打完移出遊戲（只係記錄提示）。

## 除錯
Console 有 `AG.state()` 攞遊戲狀態、`AG.start(1|2)` 開新局、`AG.render()` 重畫。
