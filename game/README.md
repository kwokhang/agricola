# Agricola — 1–2 人局（修訂版 2016）

喺瀏覽器直接開 `game/index.html` 就玩得，冇 build step、冇 server。
規則出處同細節見 [`../docs/RULES-NOTES.md`](../docs/RULES-NOTES.md)。

| 檔案 | 做乜 |
|---|---|
| `index.html` | 版面同 CSS，載入 `../data.js`、`vendor/three.min.js`、`art.js`、`cards.js`、`engine.js`、`view3d.js`、`ui.js` |
| `engine.js` | 純規則狀態機，冇 DOM；卡片效果經 hook 打入 |
| `cards.js` | A、B 兩副卡同 10 張主要發展嘅自動結算 |
| `art.js` | 全部圖畫：物資色幣圖示（`TOKEN`）、行動格插圖、卡面同卡牌插圖 |
| `view3d.js` | Three.js 檯面：行動板、兩個座位嘅農場、卡、物資全部係 3D，射線點擊接返同一套規則 |
| `ui.js` | 畫面同點擊處理，狀態存喺 `localStorage` |
| `favicon.svg` | 分頁圖示：夕陽下綠田上嘅農舍 |
| `vendor/three.min.js` | three.js r186，用 esbuild 打包成 IIFE（全域 `THREE`） |

## 版面

成個遊戲係**一張 3D 檯**：canvas 鋪滿成個視窗，HUD 面板浮喺上面（半透明玻璃質感），
唔再係一頁一頁噉睇。要至少 1000 × 560 嘅橫向視窗，細過就彈提示叫你用電腦打橫玩。

檯面係一張木檯，上面鋪住綠色絨布桌墊（有車邊線），頂上一盞暖光燈，光喺桌墊中間最亮，
四邊慢慢暗落去，檯邊隱入黑暗。木紋、絨布同背景全部用 canvas 即場畫，跟深／淺色主題變。
除咗絨布，所有嘢（板、格、卡、木件、名牌、檯面）都用同一種半光面加一層薄透明漆
（`GLOSS`），再反射一個自己砌嘅細房間（頂燈柔光箱、側窗；vendor 冇 RoomEnvironment，
用 PMREM 預先濾好），所以成張檯嘅光澤感一致。

檯上嘅嘢全部向住同一個鏡頭擺，唔使轉視點：

- **行動板**喺上面，跟返實物 1–2 人局配置：細板一行六格（農場擴建、集會所、穀物種子、
  農田、授課、散工），大板左邊一條累積格（森林、黏土坑、蘆葦地、捕魚），右邊回合格按
  階段分欄，每欄底部有收成標記。每格插圖係有光暗遠近嘅小風景，名牌寫住實際做乜同要幾多資源。
  累積落格嘅物資係一塊細圓牌，擺喺插圖左上角（唔遮名牌），面印住物資色幣，下面有數量。
- **主要發展**擺喺行動板右手邊，按類別分行、同一張卡擺埋一齊：煮食（火爐 ×2、烹飪爐灶 ×2）、
  烤麵包（黏土烤爐、石烤爐）、工坊（細木工坊、陶器坊、編籃工坊）、水井；每行左邊印住類別名。
- **兩位玩家嘅農場並排**喺行動板下面（玩家 1 橙框、玩家 2 藍框）。農場係木托盤：
  草地有花草、田有犁溝、房屋係人字頂（木屋茅草頂、黏土屋紅瓦、石屋石板瓦）、
  馬廄有交叉木門、南瓜同麥束係立體件。下面係名牌、人手（用咗嘅瞓低）、物資盤同打出咗嘅卡。
- **手牌**平時收埋，唔阻住個檯。輪到你要打職業或次要發展就自動由底下滑上嚟，
  打得嘅卡微微升高、有一圈細金邊；滑過一張會升起兼企直，畫面中間同時彈一張大卡出嚟，
  有全文、成本同「✓ 可以打出／資源唔夠」，撳一下就打出，打完又收返落去。
  檯上嘅主要發展同打出咗嘅卡，滑過都係喺中間出大卡。
  想隨時睇就撳「▲ 攤開手牌」釘住佢。
- 主要發展打得嘅會着框；已被攞走嘅卡印住邊個攞咗。
- **卡面係 TCG 式固定排版**（5:7，所有卡一樣）：名稱列（名自動縮細、右上成本寶石）、
  插圖約佔 44%、類型列（右邊分數徽章）、規則框約佔 26%（字多會自動縮細字）、底列英文名。
  手牌、檯面卡同中間大卡預覽全部用同一個卡面。
- **每張卡都有插圖**。10 張主要發展逐張畫；職業係一個工人配佢嘅
  工具，次要發展係件嘢本身。揀邊啲道具係睇卡名、再睇規則文字最先提到嘅嘢（例如「魚叉手」
  畫水同魚、「牲畜商人」畫羊同豬、講計分嘅畫金幣），背景亦跟住變（水邊、犁田、石場、牧場）。
  關鍵字表喺 `art.js` 嘅 `ART_KEYS`，想某張卡換圖改呢度就得。

鏡頭由上面斜斜望落去（離垂直大約 30–35 度，好似俯身望住張檯），唔可以自由轉——
第二行嗰排掣係**鏡頭視角**：全景／行動板／農場／卡片／主要發展。喺檯面上碌滑鼠滾輪
可以逐個切換（向下碌由全景行到主要發展，向上碌倒返轉頭）。「卡片」框住你面前打出嘅卡
（桌墊上有虛線框標住位置），同時彈出手牌；「主要發展」框住行動板右邊嗰 10 張。
遊戲會自動飛去需要嗰個視角（要放人飛去行動板、要犁田飛去農場、要打主要發展飛去主要發展；
打職業／次要發展就留喺原位，淨係彈手牌出嚟），
你手動撳完佢唔會搶返。撳對手個名牌或者頂條佢嘅玩家卡，鏡頭會移去佢嘅農場。
取景係投影包圍盒去計，會自動避開左右兩邊嘅面板，手牌彈出嚟嗰陣再讓出底下嗰截。

HUD：

- **頂條**：左邊係玩家卡（色頭像、名、「輪到」標籤、起始玩家、人手、屋種同即時分數，
  撳一下睇佢農場）；中間大回合框（回合數、階段、收成提示、14 格進度條）；右邊「☰ 選單」。
- **輪到邊個**，成個畫面就用佢嘅顏色（橙／藍）包一圈，底部有「玩家 N 嘅回合」標籤。
- **動作列**（正中下方）：而家要做乜、步驟、動作掣同「隨時可做」；換步驟會閃一下，
  手牌彈出嗰陣會升到手牌上面。
- **右欄**：上面係資源（建材／糧食／動物三行，每格圖示＋名＋數量），「▼ 其他玩家」
  攤開其他人嘅；下面係紀錄，平時收埋只顯示最新一行，撳先展開。
- 滑過行動格，左上會彈出佢做乜同累積咗幾多；卡就喺畫面中間出大卡。
- **遊戲結束**會自動彈出計分表：兩位玩家總分、勝出／平手，同每個計分項目並排對照；
  閂咗之後動作列有「睇最終分數」可以再開。
- 喺全景同行動板視角，右欄會縮成一條淨係圖示同數字嘅窄欄，滑過先展開，
  咁張檯可以用盡個畫面。
- **紀錄同計分**喺「☰ 選單」抽屜入面，設定分頁有「新遊戲」：彈出視窗揀 1 或 2 人、每人入名同揀顏色（朱、藍、若竹、江戶紫、紅梅、黃土，唔可以撞色）。遊戲結束嘅計分表同動作列都有同一個「新遊戲」掣。

開唔到 WebGL 嘅時候會退返去舊嗰套平面 SVG 板（行動板／農場／卡片三頁）。

## 搬動物

輪到你嘅時候，撳農場上有動物嘅格（牧場、馬廄，或者房屋入面嘅寵物）就拎起一隻，
再撳目的地放低，目的地一樣要有位、同一牧場只可以一種動物。拎住嘅時候再撳有同類
動物嘅格可以多拎；冇位放可以「放生」。搬位唔使用人手、唔會結束回合；手上拎住動物
嘅時候唔可以放人，要先放低。

## 自動處理
- 10 個固定行動格 + 14 張回合卡（每階段內洗勻，順序唔會提前公開）。
- 補充／工作／回家／收成四個階段，輪流放人，人用完自動跳過。
- 農場板：犁田同房間嘅相鄰限制、馬廄上限 4 個、柵欄上限 15 條。
- 牧場：柵欄圍成密封區先算牧場，容量每格 2 隻、每個馬廄翻倍，一個牧場只放一種動物；
  牧場外馬廄 1 隻、屋企養寵物（一般 1 隻，馴獸師改成每間房 1 隻）。
- 播種、收割、餵食、乞討標記、繁殖、烤麵包、「任何時候」煮食。
- 計分表全部項目，包括田上未收嘅穀物蔬菜同卡片獎勵分。

## 卡片效果
A、B 兩副（34 張 1–2 人局職業 + 48 張次要發展）連 10 張主要發展**全部自動結算**，
唔使手動加減物資。實作喺 `cards.js`，每張卡登記自己要用嘅 hook：

`onPlay`、`onRoundStart`、`onSpaceUsed`、`onAnySpaceUsed`、`onBuildRoom`、`onRenovate`、
`onPastureMade`、`onImprovement`、`onOccupation`、`onTurnEnd`、`onReturnHome`、
`beforeField`、`onField`、`bakeBonus`、`costMod`、`capacity`、`canShare`、`fenceMod`、
`free`／`doFree`、`score`。

要玩家揀嘅嘢分兩種：一係彈出選項（馴獸師、屋頂壓石工、套索），一係入面
「隨時可做」嗰行按鈕（趕羊人換動物、硬瓷換石、雜貨商、學者、犁田工⋯⋯）。
「隨時可做」真係任何時候都得：唔輪到你都撳得（要輪到自己先得嘅卡，例如季節工、手犁，卡本身會限制）。
卡放喺之後回合格嘅物資，會實物咁擺喺行動板對應回合格上（墊住玩家色圓牌），滑過嗰格會列出邊個幾時收乜；
雜貨商張卡上面疊住剩低嘅物資，鏵式犁卡上面有剩低嘅田，大卡預覽亦會寫出嚟。
放喺回合格上嘅物資（水井、大溫室、厚樹林⋯⋯）會喺該回合補充階段自動派返。

3+ 人局先用到嘅卡（p ≥ 3）唔會發到手，但簡單嗰幾張都照寫咗。

### 實作上假設咗嘅位
- **雜貨商**嘅物資疊（由頂數落：蔬菜、蘆葦、黏土、蔬菜、石頭、蘆葦、穀物、木材，共 8 件）係憑記憶跟印刷卡，未對過實卡。
- **豆田**當作卡上嘅田，只種蔬菜，收成同計分都計佢嘅蔬菜，但唔計入「田」嗰行分數。
- **小溪**「捕魚上面四格」當係森林、黏土坑、蘆葦地同第 1 回合格。
- **開墾鏟**搬作物時，來源揀作物最多嗰塊田，目的地揀第一塊空田。
- **柴火收集者**嘅木材即刻派，唔係等該人物回合真正完結。

## 除錯
Console 有 `AG.state()` 攞遊戲狀態、`AG.start(1|2)` 開新局、`AG.render()` 重畫。
3D 方面有 `View3D.debug()`（鏡頭位置、物件同貼圖數量、包圍盒）、
`View3D.focus(name, UI)` 飛去某個視角，同 `View3D.locate({type,id})` 將一個可撳物件
投影返做畫面座標——自動化測試就係靠佢喺 canvas 上面派真 PointerEvent。
可撳物件嘅 `pick` 資料有 `space`（行動格）、`tile`／`edge`（農場）、`card`（手牌同主要發展）、
`seat`（對手名牌）。

## 物資圖示

細圖靠顏色同剪影分，所以每種物資係一粒色幣加淺色剪影，色相平均分開：
木材檜皮、黏土弁柄、蘆葦苔色、石頭鈍色、穀物山吹、蔬菜柿色（綠葉）、食物蘇芳（冒煙燉菜碗）、
綿羊生成（黑面）、野豬墨（粉紅豬）、牛藍（白牛頭有角），乞討係印住 −3 嘅卡。
HUD、成本、卡面成本寶石、行動格物資牌同物資盤全部用同一套（`art.js` 嘅 `TOKEN`）。

## 色板

只得一套深色色板，全部由日本傳統色（和色）揀，放喺 `index.html` 嘅 `:root`：
墨色底、生成色字、利休鼠做次要字、山吹做唯一強調色；玩家預設朱同藍；
卡牌類型係黃土（職業）、代赭（次要發展）、弁柄（主要發展），收成用常磐；
桌墊常磐、檯面焦茶、行動板砂色。新加顏色請喺呢套入面揀，唔好再開新色相。

## 卡牌插畫

將圖擺入 `resource/occupation/`、`resource/majorimprovement/`（次要發展用 `resource/minorimprovement/`；
行動格用 `resource/action/`，檔名用行動格英文名或 id，例如 `farmexpansion.png`，建議 3:2 橫圖），
檔名用卡嘅英文名、唔理大細楷同空格，例如 `animaltamer.png` → Animal Tamer。然後行：

    python3 game/tools/build_card_images.py

佢會將每張圖縮成 900px AVIF（同畫質大細約 JPEG 三分一）、轉 base64，寫入 `game/cardimages.js`（遊戲喺 file:// 開，
SVG 貼圖讀唔到外部 PNG，所以要嵌入）。有圖嘅卡用插畫，冇圖嘅照用繪製場景。
圖可以係正方或者直圖（3:4 最啱）；職業由頂部裁（保留個頭），發展卡由中間裁。
如果張圖有一圈邊框（最少三邊有平色帶），打包時會自動裁走，並喺輸出列出。每張大約 160KB，全套都有圖嘅話要再壓細。

## 行動格

所有行動格同一個 3:2 大細（`CELL_W × CELL_H`）。細板一欄 6 格；大板 3 欄 × 6 行，
由上到下、由左到右排累積格 4 格再排回合 1–14，啱啱好排滿冇空位。收成係吊喺該回合格底邊嘅「此回合後收成」掛牌。插圖鋪滿成格（有 `resource/action/` 圖就用圖，冇就用繪製場景），
名同效果寫喺底部嘅深色漸層上面。

## 中文翻譯

遊戲內容嘅中文全部喺 `game/i18n/zh.json`：卡名同卡文（`cards`，用英文卡名做 key）、
行動格名（`spaces`，用 id）、物資名（`goods`）、屋種（`houses`）、步驟（`steps`）、
卡類（`cardTypes`）同主要發展分類（`majorRows`）。改完行：

    python3 game/tools/build_translations.py

佢會檢查 JSON 格式再生成 `game/i18n/zh.js`（file:// 讀唔到 JSON，所以要包成 script）。
存檔入面嘅卡會喺載入時更新做新字眼。`--extract` 會由遊戲資料重新抽一份 zh.json，
會蓋咗你改過嘅嘢。介面按鈕同提示文字未包喺入面。

## 卡面

- **職業卡有插畫**：全圖版（參考寶可夢全圖卡），插畫鋪滿成張卡，名同成本浮喺頂，
  規則文字喺底部漸暗位上。
- **主要發展**：ACE SPEC 版（參考寶可夢 ACE SPEC），閃箔邊框、大插畫窗、
  右下「公共卡・先建先得」。
- **其他卡**（冇插畫嘅職業、次要發展）：標準版固定分區。
所有卡嘅類型都係左下角同一款細標籤。
